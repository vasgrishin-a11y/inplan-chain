⚡ Прямое подключение к ClickHouse

Версия данных — это проект (база вида Data_public_*). После подключения выберите нужный проект и загрузите данные. Логин и данные остаются в этом браузере.
Браузер подключается к серверу напрямую, поэтому на стороне ClickHouse должен быть разрешён CORS для чужих источников. Если страница открыта по HTTPS, а ClickHouse работает по HTTP, браузер блокирует «смешанное» содержимое — в этом случае запрос идёт через прокси локального сервера синхронизации (`server/index.js`, endpoint `/api/clickhouse/proxy`), а настройки подключения (HTTP, порт, логин) остаются без изменений. Если сервера синхронизации нет, хост ClickHouse должен отвечать по HTTPS с действующим сертификатом (самоподписанные сертификаты браузер блокирует). Пароль передаётся параметром запроса — используйте аккаунт с правами только на чтение.
Локальный HTTPS-прокси: https://127.0.0.1:8443; учётные данные указываются при запуске прокси. Поля логина и пароля на публичном сайте не используются.
