# In.Plan · сервер синхронизации (прототип)

Опциональный бэкенд для дашборда `index.html`. Нужен, только когда моделью
пользуются несколько человек и хочется общее состояние вместо localStorage
у каждого в браузере.

**Дашборд остаётся самодостаточным.** Без сервера он работает ровно как
раньше: локальные данные, TTL 24 часа, открытие двойным кликом по файлу.

## Запуск

Нужен только Node.js 18+. Зависимостей нет — ни `npm install`, ни
`package.json`.

```bash
node server/index.js
# In.Plan sync server → http://localhost:8137
```

Порт и каталог данных настраиваются переменными окружения:

```bash
PORT=9000 node server/index.js
```

Сервер раздаёт и сам дашборд: откройте <http://localhost:8137/> — это тот же
`index.html`, но индикатор в шапке загорится зелёным «Сервер».

## Модель хранения: ревизии, а не перезапись

Каждая отправка создаёт **новую ревизию** с собственным номером. Ничего
никогда не перезаписывается и не удаляется. Если кто-то зальёт кривую книгу,
предыдущее состояние доступно по номеру — для команды без логинов это главная
страховка от «а кто это сломал».

Данные лежат в `server/data/` (в Git не попадает, см. `.gitignore`):

```
server/data/
  index.json            метаданные всех ревизий
  revisions/1.json      полная модель ревизии 1
  revisions/2.json      ...
```

## API

Все ответы — JSON. CORS разрешён, чтобы дашборд работал и с другого хоста.

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/health` | Проверка соединения: `{ ok: true, latest, revisions }` |
| `GET /api/model` | Последняя ревизия целиком |
| `GET /api/model?id=N` | Ревизия N целиком — так откатываются к старому состоянию |
| `GET /api/revisions` | История: id, время, автор, число строк по разделам |
| `POST /api/model` | Создать ревизию из тела запроса |

### POST /api/model

```json
{
  "author": "Иванов",
  "note": "загрузка из книги за сентябрь",
  "model": { "sku": [], "res": [], "prodsource": [], "tlane": [] }
}
```

Ответ — метаданные созданной ревизии:

```json
{ "ok": true, "revision": { "id": 7, "savedAt": 1757000000000, "author": "Иванов", "rows": 1043,
  "counts": { "sku": 500, "res": 43, "prodsource": 100, "tlane": 400 } } }
```

Разделы, отсутствующие в теле, сохраняются пустыми; посторонние поля
отбрасываются. Лимит тела — 32 МБ.

### Примеры

```bash
curl http://localhost:8137/api/health
curl http://localhost:8137/api/revisions
curl 'http://localhost:8137/api/model?id=3' -o rev3.json
curl -X POST http://localhost:8137/api/model \
     -H 'Content-Type: application/json' \
     -d '{"author":"test","model":{"sku":[],"res":[],"prodsource":[],"tlane":[]}}'
```

## Границы прототипа

Осознанно не сделано: аутентификация, права, блокировки, удаление ревизий,
сжатие истории. Это инструмент для маленькой доверенной команды во внутренней
сети, а не публичный сервис.
